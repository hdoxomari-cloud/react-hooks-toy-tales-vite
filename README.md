Toy Tales

Description

Toy Tales is a React application that helps Andy manage his toy collection. Users can view toys, add new toys, increase their likes, and donate toys by removing them from the collection.

The application uses a JSON Server backend to store and manage toy data.

Features

View Toys: Fetches and displays all toys from the database when the application loads.

Add a Toy: Allows users to add a new toy with a name and image URL. New toys start with zero likes.

Like a Toy: Increases the like count of a selected toy and updates the database.

Donate a Toy: Removes a selected toy from the collection and database.
